# Référence administrative France

`cog-2026-chefs-lieux.json` est un extrait du [Code officiel géographique 2026
de l’Insee](https://www.insee.fr/fr/information/8740222), téléchargé le 8 novembre
2026. Il sert de référence indépendante aux tests des 101 départements et des
18 régions ; il n’est pas téléchargé pendant une session de jeu.

Extraction des colonnes CODE, LIBELLE, REG et CHEFLIEU, avec résolution des
codes de chefs-lieux vers les noms de communes dans les fichiers officiels :

- [Départements](https://www.insee.fr/fr/statistiques/fichier/8740222/v_departement_2026.csv)
- [Régions](https://www.insee.fr/fr/statistiques/fichier/8740222/v_region_2026.csv)
- [Communes](https://www.insee.fr/fr/statistiques/fichier/8740222/v_commune_2026.csv)

Données Insee, [Licence Ouverte Etalab 2.0](https://www.etalab.gouv.fr/licence-ouverte-open-licence/).
